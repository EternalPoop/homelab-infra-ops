# 1단계 가상화 환경
작업일: 2026-10-17

## 목표
- PC 한 대에 서버 VM 4대를 올릴 가상화 환경 구성
- 모든 VM을 하나의 내부망(10.10.10.0/24)에 고정 IP로 연결

## 환경
| 항목 | 내용 |
| --- | --- |
| 하이퍼바이저 | Oracle VirtualBox |
| 선택 이유 | 개인 PC에서 바로 쓸 수 있는 무료 타입 2 하이퍼바이저. 가상 네트워크·스냅샷 개념은 실무 VMware ESXi와 같음 |

## 네트워크 설계
- VirtualBox NAT 네트워크 `LabNet` : 10.10.10.0/24
- 게이트웨이 10.10.10.1 (NAT 네트워크 기본값)
- DHCP 사용X: 서버 IP가 바뀌면 DNS, 방화벽, 모니터링 설정이 모두 어긋나기 때문

## VM 생성 기록
| VM | 생성일 | vCPU | 메모리 | 디스크 | 네트워크 |
| --- | --- | --- | --- | --- | --- |
| lin01 | 2026-10-17 | 2 | 2GB | 20GB | NAT 네트워크 LabNet |

## 문제/해결
- 문제: VMware Workstation 다운로드 경로(Broadcom 포털)에서 제품이 검색되지 않음
- 해결: 무료로 바로 쓸 수 있는 VirtualBox로 변경. NAT 네트워크 게이트웨이가 VMware(.2)와 달리 .1인 점을 확인하고 IP 설계에 반영
- 문제: VM 생성 시 무인 설치(Unattended Installation)가 기본으로 체크되어 있음
- 해결: 설치 과정을 직접 익히기 위해 체크 해제
- 문제: 어댑터 1이 기본값 NAT로 되어 있어 VM끼리 같은 내부망을 쓸 수 없음
- 해결: Attached to를 NAT 네트워크, 이름 LabNet으로 변경

## 배운 점
- NAT는 VM 하나가 단독으로 밖에 나가는 방식, NAT 네트워크는 여러 VM이 같은 내부망을 공유하는 방식
- VirtualBox는 타입 2(OS 위에 설치), 실무 ESXi는 타입 1(장비에 직접 설치) 하이퍼바이저
